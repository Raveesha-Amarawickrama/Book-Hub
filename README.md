# 📚 Book Hub – Online Book Management System

**Book Hub** is a PHP-based web application that allows users to browse, upload, and manage books in a digital library. Designed for students, educators, and administrators to streamline access to reading materials.

---

## 🚀 Features

- 📖 Upload and manage books (PDFs, images)
- 👤 User registration and login
- 🗂️ Admin panel for book and user management
- 🔍 Search and filter functionality
- 📂 Book cover image uploads
- 📁 Organized folder structure using Composer

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Package Management:** Composer
- **File Handling:** Local uploads
  
- **Folder Structure:**
- ├── assets/ → Images, icons
├── css/ → Custom styles (e.g., admin_nav.css)
├── js/ → Client-side scripts (e.g., admin_nav.js)
├── public/ → Main entry points (e.g., index.php, profile.php)
├── uploads/ → Uploaded book files (images/docs)
├── composer.json → PHP package management
└── composer.lock → Lock file for installed dependencies
